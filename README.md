# 🌤️ React Weather Dashboard

A responsive weather dashboard built with React.js and OpenWeather API. The application provides current weather information, location-based weather, a 5-day forecast, recent searches, dark mode, and automatic weather updates.

## 🚀 Features

* 🔎 Search weather by city
* 📍 Get weather using current location
* 🌡️ Current temperature and feels-like temperature
* 💧 Humidity information
* 💨 Wind speed
* 🌡️ Atmospheric pressure
* 👁️ Visibility information
* 📅 5-day weather forecast
* 🌤️ Dynamic weather icons
* 🌈 Weather-based background
* 🌙 Dark/Light mode
* 🔄 Manual weather refresh
* ⏱️ Automatic weather refresh
* 🕘 Recent city searches
* ⚠️ Loading and error handling
* 📱 Responsive design

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open the project:

```bash
cd weather-app
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the project root:

```env
VITE_WEATHER_API_KEY=YOUR_API_KEY
```

Start the development server:

```bash
npm run dev
```

## 🔑 API


This project uses the OpenWeather API to retrieve current weather and forecast information.
